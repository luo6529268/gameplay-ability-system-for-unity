## 写冲突与证据失效

只读分析可并行，代码任务独立且写域不重叠才委派；架构/合同决定与最终集成留主代理。
字段、候选顺序、发布时点或Kernel变化可能使相关正确性证据过期；资源身份/模式变更可能使性能基线不再可比；不触及相应依赖的修改不要求全量重跑。取哈希不等于已核行为，复用理由要写入具名Task。
