## 1. Authority / 差异

C++ release `cpoint.cpp:35-124` 和 `weapon.cpp:42-48` 的指定 CPoint branches 直接写 frame，
但不写相邻 wait state。Unity `BattleCpointWriter` 的七个对应 callsite 使用
`DirectWriteFrameImmediateWaitReset` 或 `ApplySignedImmediateFrameWaitReset`，它们经
`LF2Entity.SetFrameTickImmediateRawDirect` 额外清 `Runtime.FrameWaitCounter`。

已有 `DirectWriteRawFramePreserveWaitCounter` 与 `ApplySignedCpointFrame` 能保持
frame/facing/Frame.D/Trans mirror，同时不清该 runtime state，并保留 C++ 所需的 missing raw-frame 写入语义。
