The same source edge thus maps to the same physical integer edge on both entities; casting follows the existing runtime truncation and `ClampRect` remains the query's saturation. Identity-scale path retains its current physical integer arithmetic exactly. If an entity has no initialized source carrier, derive one source center through `ViewToSourceX` and use the same projection; that fallback is explicit, not an assumption that every old fixture has a carrier. For configured battles, exact Z admission compares source-carrier integer depths against the existing selected attack radius; physical AABBs conservatively enclose the corresponding projected source radius. `RoleAwareFormalParticipant` must cache the selected source X and Z beside existing physical X/Y to invalidate stale exact rects. Immediate volume inputs remain physical and body volumes must express projected physical width/depth. The separate platform ITR path requires its own source-snapshot classification before edit; do not silently include it in the ordinary candidate GREEN claim. Formal C++ `CollisionGeometry28::project` uses int64 source X, strict X/Y `<`, attack zero-zwidth fallback15, optional held override, and Z center offset.
