# LF2 角色动画帧预览器 - 使用说明

## 功能概述

**CharacterFramePreviewWindow** 是一个完整的 LF2 风格动画帧预览和调试工具，完全复刻了 `LF2CharacterAnimator` 的播放逻辑。

---

## 打开窗口

菜单路径：`NTSD → Animation → Frame Preview Window`

---

## 核心功能

### 1. 角色选择

- **角色ID下拉框**：从已加载的角色中选择
- **角色名称显示**：自动显示选中角色的名称

### 2. 帧控制

- **起始帧ID**：设置播放的起始帧
- **当前帧ID**：显示当前正在播放的帧
- **帧名称**：显示当前帧的名称（如 "standing", "walking" 等）
- **当前状态**：显示当前帧的状态值（State）

### 3. 播放控制

| 按钮 | 功能 | 颜色 |
|------|------|------|
| **播放** | 从起始帧开始播放，到达终止帧（next=0/999/1000）后停止 | 绿色 |
| **循环播放** | 播放到终止帧后自动回到起始帧继续播放 | 蓝色 |
| **停止** | 停止当前播放 | 红色 |
| **重置** | 回到起始帧并停止播放 | 橙色 |

### 4. 播放状态监控

实时显示以下信息：
- **播放中**：是否正在播放
- **循环模式**：是否为循环播放
- **等待计数**：当前剩余的等待帧数（对应 JSON 的 `wait` 字段）
- **下一帧**：下一帧的ID（对应 JSON 的 `next` 字段）
- **等待时间**：当前帧的总等待时间
- **精灵索引**：当前帧使用的精灵图索引（对应 JSON 的 `pic` 字段）

### 5. 精灵预览

- **400x400 像素**的精灵预览区域
- 自动显示当前帧对应的精灵图
- 支持透明背景显示

### 6. 帧详细信息

可折叠的详情面板，显示：
- **当前帧数据**：完整的 `LF2FrameData` 对象
- **碰撞盒数量**：bodies 数组长度
- **攻击判定数量**：itrs 数组长度
- **MP消耗**：该帧消耗的 MP 值

### 7. 播放速度控制

- **播放速度倍率**：0.1x ~ 5x（默认 1x）
- **FPS显示**：实时显示当前播放的 FPS（基准30 FPS）

## 完整工作流程

### 步骤1：选择角色

```
1. 打开窗口：NTSD → Animation → Frame Preview Window
2. 在"角色选择"区域，从下拉框选择角色ID（如 2=Naruto）
3. 确认"角色名称"显示正确
```

### 步骤2：设置起始帧

```
1. 在"帧控制"区域，输入起始帧ID（如 0=Standing）
2. 观察预览区域显示对应的精灵图
3. 查看"帧名称"和"当前状态"确认是否正确
```

### 步骤3：播放动画

**单次播放：**
```
1. 点击"播放"按钮
2. 动画会按照 JSON 的 wait 和 next 字段自动播放
3. 到达终止帧（next=0/999/1000）后自动停止
4. 观察"等待计数"实时递减
```

**循环播放：**
```
1. 点击"循环播放"按钮
2. 播放到终止帧后会自动回到起始帧
3. 持续循环直到手动点击"停止"
```

### 步骤4：调整播放速度

```
1. 拖动"播放速度倍率"滑条
2. 0.1x = 慢动作（3 FPS）
3. 1.0x = 正常速度（30 FPS）
4. 5.0x = 快进（150 FPS）
```

## 核心逻辑说明

### 播放循环（完全复刻 LF2CharacterAnimator）

```csharp
每帧更新（30 FPS）：
1. 如果 currentWaitCount > 0：
   - 递减 currentWaitCount
   - 保持当前帧不变

2. 如果 currentWaitCount = 0：
   - 读取当前帧的 next 字段
   - 判断 next 是否为终止帧（0, 999, 1000）

   如果是终止帧：
      - 非循环模式：停止播放
      - 循环模式：回到起始帧

   如果不是终止帧：
      - 切换到 next 指定的帧
      - 重置 currentWaitCount = 新帧的 wait 值
```

### 与 JSON 文件的对应关系

```json
{
  "frameId": 0,        // 帧ID - 用于索引和跳转
  "frameName": "standing",  // 帧名称 - 显示在界面上
  "pic": 0,            // 精灵索引 - 决定显示哪个精灵图
  "state": 0,          // 状态值 - 用于状态分组
  "wait": 3,           // 等待帧数 - 该帧停留的时间（帧）
  "next": 1            // 下一帧ID - 等待结束后跳转到此帧
}
```

### 终止帧判断规则

| next 值 | 含义 | 行为 |
|---------|------|------|
| `0` | 终止 | 停止播放或循环回起始帧 |
| `999` | 终止 | 停止播放或循环回起始帧 |
| `1000` | 终止 | 停止播放或循环回起始帧 |
| 其他值 | 跳转 | 切换到对应帧ID |

## 与 FLF 源码的对应关系

本预览器完全复刻了 FLF 的动画播放逻辑：

| FLF 组件 | 预览器对应部分 |
|----------|---------------|
| `TU_update()` | `UpdateFrame()` |
| `frame_update()` | `FrameUpdate()` |
| `currentWaitFrame--` | `currentWaitCount--` |
| `nextFrameId = currentFrame.next` | `nextFrameId = currentFrame.next` |
| `trans.SetWait()` | `currentWaitCount = frame.wait` |
| `trans.SetNext()` | 直接读取 `frame.next` |

## 注意事项

### 1. 数据源依赖

**必须先加载角色数据**：
- 确保 `CharacterAnimtorManager` 已初始化
- JSON 文件必须存在于 `Assets/NTSD/Config/AnimationConfig/` 目录
- 精灵图必须已成功裁剪和加载

### 2. 性能考虑

- 默认 30 FPS 播放
- 编辑器模式下性能可能略有波动
- 建议播放速度不超过 5x

### 3. 已知限制

- 不支持实时编辑 JSON（需要重新加载）
- 不支持显示碰撞盒和攻击判定可视化（计划中）
- 不支持音效播放（计划中）

## 故障排查

### 问题1：窗口无法打开

**解决方案**：
```
1. 确认 OdinInspector 已安装
2. 检查脚本编译是否成功
3. 重新导入脚本
```

### 问题2：精灵不显示

**解决方案**：
```
1. 检查 CharacterAnimtorManager 是否已初始化
2. 确认角色ID和帧ID是否正确
3. 查看 Console 是否有加载错误
4. 点击 CharacterAnimtorManager 的"刷新所有数据"按钮
```

### 问题3：播放速度异常

**解决方案**：
```
1. 检查播放速度倍率是否在 0.1-5.0 范围内
2. 重置速度倍率为 1.0
3. 重新打开窗口
```

### 问题4：循环播放不工作

**解决方案**：
```
1. 检查 JSON 的 next 字段是否正确设置终止值（0/999/1000）
2. 使用"打印播放路径"工具检查是否存在死循环
3. 确认起始帧是否有效
```
