# LF2 动画帧预览器 - 快速入门

## 🚀 30秒快速开始

### 步骤1：打开窗口
```
菜单：NTSD → Animation → Frame Preview Window
```

### 步骤2：选择角色和帧
```
1. 角色ID：2（鸣人）
2. 起始帧ID：0（站立）
```

### 步骤3：播放
```
点击"循环播放"按钮
```

**就这么简单！你应该看到鸣人的站立动画循环播放了。**

---

## 💡 核心概念（5分钟理解）

### 什么是"帧"？

在 LF2 中，每个角色的动画由**帧（Frame）**组成。每一帧包含：

```json
{
  "frameId": 0,        // 这是第0帧
  "pic": 0,            // 显示第0张图片
  "wait": 3,           // 停留3帧时间（0.1秒 @ 30FPS）
  "next": 1            // 然后跳到第1帧
}
```

### 播放逻辑

```
帧0（站立第1张）→ 等待3帧 → 帧1（站立第2张）→ 等待3帧 → 帧2...
```

### 什么是"终止帧"？

当 `next` 为 `0`, `999`, 或 `1000` 时，动画结束：
- **非循环模式**：停止播放
- **循环模式**：回到起始帧

## 🐛 常见问题

### Q1：精灵不显示？

**A1**：确保 CharacterAnimtorManager 已加载数据
```
1. 找到场景中的 CharacterAnimtorManager
2. 点击 Inspector 中的"刷新所有数据"按钮
3. 查看 Console 确认加载成功
```

---

### Q2：播放停不下来？

**A2**：检查 JSON 的 next 字段
```
正确的终止帧：
"next": 0    ✅
"next": 999  ✅
"next": 1000 ✅

错误的配置：
"next": 5    ❌（会跳到帧5）
```

---

### Q3：播放太快/太慢？

**A3**：调整播放速度倍率
```
慢动作：0.1x - 0.5x
正常：1.0x
快进：2.0x - 5.0x
```

## 🎓 进阶技巧

### 技巧1：打印播放路径

想知道一个技能的完整播放顺序？

```
1. 设置起始帧为技能第一帧
2. 点击"打印播放路径"按钮
3. 查看 Console 输出：
   60 → 61 → 62 → 63 → 64 → 65 → 999
```

---

### 技巧2：查看所有状态

不知道某个技能从哪一帧开始？

```
1. 点击"列出所有状态帧"按钮
2. 查看 Console 输出：
   状态 0: standing (帧 0-9)
   状态 1: walking (帧 10-19)
   状态 301: attack1 (帧 60-65)
```

---

### 技巧3：逐帧分析

需要仔细查看某一帧？

```
1. 设置播放速度为 0.1x
2. 点击"播放"
3. 观察"等待计数"从 wait 值递减到 0
4. 切换帧时会有日志输出
```

## 🌟 一些有趣的事

### 发现1：站立动画的秘密

```
站立动画通常是：
0 → 1 → 2 → 3 → 4 → 5 → 0（循环）

每帧 wait=3，总共 18 帧 = 0.6 秒一个循环
这就是角色"呼吸"的效果！
```

---

### 发现2：技能的"收招"

```
攻击技能通常：
60（起手）→ 61（蓄力）→ 62（出招）→ 63（收招）→ 999（结束）

wait 值通常：
起手 wait=2（快速）
蓄力 wait=5（慢一点）
出招 wait=1（瞬间）
收招 wait=3（恢复中）
```

---

### 发现3：next 可以"跳帧"

```
不一定是 0→1→2→3
也可以是 0→2→5→999（跳过某些帧）

这用于：
- 多个分支选择（普通攻击 vs 强力攻击）
- 技能升级（跳过起手动画）
- 连招系统（直接进入下一招）
```
