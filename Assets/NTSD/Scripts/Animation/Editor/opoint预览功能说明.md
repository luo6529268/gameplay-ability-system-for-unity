# opoint 对象预览功能 - 完整说明

## ✅ 已实现的功能

### 1. 数据解析
- **DataFileParser.cs**：解析 `Assets/NTSD/Config/data.txt` 文件
- 提取所有对象定义（id, type, file）
- 支持不同路径格式和注释

### 2. 可视化预览
在预览窗口的精灵预览区域，现在可以同时显示：

#### 主角色精灵
- 居中显示
- 2倍放大
- 600x400像素预览区域
- 背景网格辅助定位

#### opoint 对象显示（两种模式）

**模式A：真实精灵显示**（当对象精灵已加载时）
- 绿色边框标识对象精灵
- 80% 不透明度（便于区分主角色）
- 根据 FLF 逻辑精确定位
- 自动支持朝向镜像

**模式B：占位框显示**（当对象精灵未加载时）
- 红色半透明框标记对象位置
- 显示 oid、action、帧名称
- 提示需要加载对象数据

#### 速度矢量可视化
- 黄色箭头显示飞行方向
- 基于 dvx, dvy 计算
- 显示速度数值

### 3. 位置计算（严格遵循 FLF 逻辑）

```csharp
// 朝右：
对象x = 角色精灵左上角x + opoint.x * 缩放

// 朝左（镜像）：
对象x = 角色精灵右上角x - opoint.x * 缩放

// 垂直位置：
对象y = 角色精灵左上角y + opoint.y * 缩放
```

### 4. 信息显示

#### 顶部信息栏
- 精灵名称
- 精灵尺寸
- 当前帧ID
- opoint 状态（有/无，oid）

#### 帧详细信息区域
- 对象点状态（true/false）
- 完整的 opoint 参数：
  - oid（对象ID）
  - 对应的文件路径
  - action（对象起始帧）
  - pos (x, y)（相对位置）
  - vel (dvx, dvy)（初始速度）
  - facing（朝向控制）

### 5. 调试工具

**"打印对象点(opoint)信息"按钮**：
- 打印当前帧的完整 opoint 数据
- 显示对象定义（文件路径、type）
- 加载对象数据并验证
- 检查对象帧是否存在
- 检查对象精灵是否已加载
- 给出加载提示

## 📋 使用说明

### 基础使用

1. **打开预览窗口**
   ```
   菜单：NTSD → Animation → Frame Preview Window
   ```

2. **查看有 opoint 的帧**
   - 选择角色（如鸣人 ID=2）
   - 找到技能释放帧（如投射技能）
   - 在预览区域会看到：
     - 中心的角色精灵
     - 红框/绿框标记的对象位置
     - 黄色箭头显示飞行方向

3. **查看详细信息**
   - 展开"帧详细信息"
   - 查看"对象点详情"
   - 点击"打印对象点(opoint)信息"

### 加载对象精灵（显示真实精灵）

如果想看到真实的对象精灵（而不是红色占位框），需要：

1. **在场景中找到 CharacterAnimtorManager**

2. **加载对象数据**
   - 在 Inspector 中找到"操作按钮"区域
   - 点击"刷新所有数据"按钮
   - CharacterAnimtorManager 会加载所有角色和对象

3. **验证加载**
   - 回到预览窗口
   - 点击"打印对象点(opoint)信息"
   - 查看是否显示"✅ 对象精灵已加载"

4. **查看效果**
   - 红色占位框会变成绿色边框的真实精灵
   - 位置和大小严格按照 FLF 逻辑计算

## 🎯 视觉标识说明

| 颜色 | 含义 | 说明 |
|------|------|------|
| **红色框** | 对象占位符 | 对象数据已加载，但精灵未加载 |
| **绿色框** | 真实对象精灵 | 对象精灵已成功加载并显示 |
| **黄色箭头** | 速度矢量 | 显示对象的初始飞行方向 |
| **红色十字线** | 预览中心 | 角色精灵的中心参考线 |
| **灰色网格** | 背景网格 | 50像素间隔，辅助定位 |

## 🔍 实际案例

### 案例：鸣人的螺旋手里剑

假设在某一帧有以下 opoint：
```json
{
    "x": 40,      // 右手前方40像素
    "y": -30,     // 手的高度（向上偏移）
    "dvx": 12,    // 快速向前飞
    "dvy": 0,     // 水平飞行
    "oid": 229,   // 螺旋手里剑对象
    "action": 70, // 对象的初始帧
    "facing": 0   // 跟随角色朝向
}
```

**预览效果**：
1. 中心显示鸣人精灵
2. 右手前方（x=+40）位置显示对象
3. 位置略微向上（y=-30）
4. 黄色箭头向右指，标注 (12, 0)
5. 如果精灵已加载：显示螺旋手里剑的真实图案（绿框）
6. 如果精灵未加载：显示红色占位框，标注 oid:229

## ❓ 常见问题

### Q1：为什么只显示红色框，看不到对象精灵？

**A1**：对象精灵未加载。

**解决方案**：
1. 找到场景中的 CharacterAnimtorManager
2. 点击"刷新所有数据"
3. 等待加载完成
4. 重新打开预览窗口

### Q2：对象位置看起来不对？

**A2**：可能是朝向问题。

**当前限制**：暂时默认朝向为右，朝左时位置可能不准确。

**临时解决方案**：选择朝右的角色帧进行预览。

### Q3：如何找到有 opoint 的帧？

**A3**：使用调试工具。

**方法**：
1. 打开预览窗口
2. 选择角色
3. 点击"列出所有状态帧"
4. 查看技能状态（通常 state > 300）
5. 逐个查看这些帧
6. 查看"帧详细信息"中的"对象点"字段
