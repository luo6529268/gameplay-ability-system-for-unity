🎯 点类型 (Points)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ 武器点 (wpoint - Weapon Point)
────────────────────────────────────────────────────────────────
kind         int     武器点类型                     1
x            int     X坐标                          45
y            int     Y坐标                          29
weaponact    int     武器动作                       100
attacking    int     攻击状态                       0
cover        int     覆盖状态                       1
dvx          int     X轴速度                        0
dvy          int     Y轴速度                        0
dvz          int     Z轴速度                        0

示例：
wpoint:
   kind: 1  x: 45  y: 29  weaponact: 100  attacking: 0  cover: 1
   dvx: 0  dvy: 0  dvz: 0
wpoint_end:

────────────────────────────────────────────────────────────────

2️⃣ 碰撞盒 (bdy - Body)
────────────────────────────────────────────────────────────────
kind         int     碰撞盒类型                     0
x            int     X坐标                          21
y            int     Y坐标                          18
w            int     宽度                           43
h            int     高度                           62

特殊Y值：
  60000      特殊标记（无敌？）
  80000      特殊标记（影子层？）
  130000     特殊标记

示例：
bdy:
   kind: 0  x: 21  y: 18  w: 43  h: 62
bdy_end:

────────────────────────────────────────────────────────────────

3️⃣ 交互区域 (itr - Interaction Area)
────────────────────────────────────────────────────────────────
kind         int     交互类型                       0
x            int     X坐标                          21
y            int     Y坐标                          57
w            int     宽度                           37
h            int     高度                           24
zwidth       int     Z轴宽度                        0
injury       int     伤害值                         50
fall         int     击倒值                         20
arest        int     攻击硬直                       10
vrest        int     受击硬直                       15
effect       int     效果ID                         0

示例：
itr:
   kind: 0  x: 21  y: 57  w: 37  h: 24  zwidth: 0
   injury: 50  fall: 20  arest: 10  vrest: 15  effect: 0
itr_end:

────────────────────────────────────────────────────────────────

4️⃣ 对象点 (opoint - Object Point)
────────────────────────────────────────────────────────────────
kind         int     对象类型                       1
action       int     动作ID                         200
objectId     int     对象ID（id字段）               203
x            int     X坐标                          43
y            int     Y坐标                          81
dvx          int     X轴速度                        0
dvy          int     Y轴速度                        0
oid          int     对象ID（oid字段）              203
facing       int     朝向                           0

示例：

   kind: 1  action: 200  id: 203  x: 43  y: 81
   dvx: 0  dvy: 0  oid: 203  facing: 0
opoint_end:

5️⃣ 血点 (bpoint - Blood Point)
────────────────────────────────────────────────────────────────

示例：
bpoint:
   x: 30  y: 40
bpoint_end:

6️⃣ 抓取点 (cpoint - Catch Point) ⭐ 新增
────────────────────────────────────────────────────────────────
kind         int     抓取点类型                     1
x            int     X坐标                          95
y            int     Y坐标                          39
fronthurtact int     正面受击动作                   55
backhurtact  int     背面受击动作                   55
vaction      int     V动作                          130
throwvz      int     投掷Z轴速度                    -842150451
hurtable     int     是否可伤害                     1
throwinjury  int     投掷伤害                       -842150451
decrease     int     递减值                         10

示例：
cpoint:
   kind: 1  x: 95  y: 39
   fronthurtact: 55  backhurtact: 55
   vaction: 130  throwvz: -842150451  hurtable: 1
   throwinjury: -842150451  decrease: 10
cpoint_end:

📝 注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 可选字段：dvz、mp、cpoint等字段为可选，只在需要时出现
2. 特殊值：某些字段可能有特殊含义的值（如bdy的y: 80000）
3. 负值：mp可以为负值（表示恢复能量）
4. 大数值：某些字段（如throwvz）可能是非常大的数值
5. 默认值：未指定的字段使用默认值（通常为0或null）
