## 🔔 更新规则（重要！）

### Claude 必须遵守的规则

1. **每次完成任务后**：
   - ✅ 更新"已完成任务"章节，标记为 `[x]`
   - ✅ 添加完成时间和完成人
   - ✅ 更新"当前状态"
   - ✅ 更新"整体进度"
   - ✅ 提醒用户推送到 Git

2. **每次开始新任务前**：
   - ✅ 读取本文件，确认当前进度
   - ✅ 更新"当前任务"
   - ✅ 更新"最后操作时间"

3. **遇到问题时**：
   - ✅ 同时更新 `ISSUES.md`
   - ✅ 在任务备注中记录问题编号

4. **发现需要调整配置时**：
   - ✅ 同时更新 `CONFIG.md`
   - ✅ 在任务备注中说明调整原因

### 用户必须做的事

1. **每次完成任务后**：
   - ✅ 推送到 Git：`git add . && git commit -m "完成 Phase A1" && git push`

2. **切换电脑前**：
   - ✅ 确保已推送最新进度

3. **切换电脑后**：
   - ✅ 拉取最新代码：`git pull`
   - ✅ 在新对话中让 Claude 读取 `PROGRESS.md`
