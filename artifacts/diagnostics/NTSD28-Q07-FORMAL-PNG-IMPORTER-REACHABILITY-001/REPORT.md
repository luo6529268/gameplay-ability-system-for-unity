# Q07 formal PNG importer reachability audit (2026-09-22)

Status: `VERIFIED_STATIC_IMPORTER_SCOPE_ONLY`. This is a read-only raw PNG/header, `.meta`, C# reader, and serialized-GUID inventory. It does not claim Unity visual parity or authorize a blanket importer change.

The staged `Assets/NTSD/Content/LoganRuntime` contains 1,010 PNG files and 1,010 PNG `.meta` GUIDs. Raw PNG IHDR dimensions show 1,009 non-power-of-two images. Of these, 1,008 have `nPOTScale: 1`; only the explicitly re-bound `vfs/c/sasu/sasu.png` has `nPOTScale: 0`. The remaining power-of-two PNG also has `nPOTScale: 1`. This is an importer-risk inventory, not evidence that 1,008 runtime textures are incorrectly sized.

Across all 719 `.unity`, `.prefab`, and `.asset` YAML files under `Assets`, exactly one serialized reference targets a formal PNG GUID: `Assets/NTSD/Scene/NTSD_Battle.unity:3053` points to `vfs/c/sasu/sasu.png`, whose importer is already set to `nPOTScale: 0`. A broader scan of 6,109 non-formal text assets (including `.mat`, animation, controller, atlas, UI, config, and `.meta` files) found the same sole reference; the 1,010 formal PNG `.meta` self-declarations were excluded rather than mistaken for consumers. The only direct `AssetDatabase.LoadAssetAtPath<Texture2D>` callsites in NTSD scripts are the Sasuke editor sample and its focused tests (`BattleCentralEditorPreviewEditor.cs:206`, `BattleCentralEditorPreviewEditorTests.cs:26,731`). No other current serialized or direct editor Texture2D caller was found for the 1,008 untouched NPOT PNGs.

The default battle content root is `Assets/NTSD/Content/LoganRuntime` in `GameConfig.asset`. The production image path reads file bytes and creates textures from decoded image dimensions: `BMPLoader.cs:79,131-135,170-174` and `CharacterAnimtorManager.cs:1687-1693`; it does not use these imported Texture2D GUIDs. The raw-file source path and existing Q07 publication/Player evidence are separate from Unity's asset importer path. Dynamic/reflection/custom AssetDatabase consumers outside the searched NTSD scripts cannot be ruled out by this inventory.

Decision for current Q07 scope: keep the exact Sasuke importer fix and the pending Editor preview validation; do not batch-change 1,008 unrelated `.meta` files merely because their images are NPOT. If a later Scene, Prefab, or editor tool binds another formal PNG as a Unity `Texture2D`, inspect its raw/imported dimensions and set that asset's importer under a separate exact Task/Change. No PNG, `.meta`, Scene, script, or nonbattle file was modified by this audit.
