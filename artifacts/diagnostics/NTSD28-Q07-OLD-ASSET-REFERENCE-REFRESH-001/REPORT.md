This is a static reference graph, **not** a complete dynamic reachability or deletion certificate. Script-composed paths, reflection, editor-only loads, encrypted DAT declarations and runtime selection can evade exact literals and serialized GUID scans. The 383 old indexed images are not automatically safe to remove merely because only one has a GUID reference; their old DAT text and legacy loader can refer to them by path. The 174 other-image rows include protected UI, map and backgrounds. `deleteAuthorized` remains false for every row. Any future removal needs a separate exact file list, rebind/consumer plan, required approval under the repository rules and a fresh validation boundary; do not delete whole Config or Sprite directories.
