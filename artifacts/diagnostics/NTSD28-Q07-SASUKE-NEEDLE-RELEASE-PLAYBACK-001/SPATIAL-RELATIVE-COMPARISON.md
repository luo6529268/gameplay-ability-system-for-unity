# Sasuke needle tick-15 relative-birth comparison (2026-09-25)

This is a read-only comparison of two existing, independent observations: root formal EXE trace `formal_release_explicit_vfs_trace.jsonl` from the 26-packet playback, and original-project Unity Battle Scene physical-input result `../NTSD28-Q07-SASUKE-NEEDLE-PHYSICAL-001/q07-sasuke-needle-2.json`. No new formal EXE or Unity run was performed.

Both observations first show four OID440 children at tick15 while Sasuke is on action/frame264. The formal EXE parent integer position is `(500,0,542)`, Unity's is `(800,0,714)`; absolute coordinates therefore cannot be compared directly. After subtracting each observed parent position from its own four child positions, both yield `(1,-33,1)` for each child. Comparing slot-ordered children 50–53, all four `(vx,vy,vz)` vectors match exactly: `(35,4,-5)`, `(38.333333333333336,4,-1.6666666666666665)`, `(38.333333333333336,4,1.666666666666667)`, `(35,4,5)`. The raw Unity JSON serializes one `vx` as `38.333333333333339`; PowerShell double parsing yields the same binary64 value as the formal trace. A programmatic comparison of 4 children × 6 numeric fields (relative x/y/z and vx/vy/vz) found **24/24 equal, maximum absolute difference 0**. All four have end-of-tick action/frame2 and pic1 in both observations.

This strengthens the Q07 scoped Sasuke birth-placement and spread-velocity evidence beyond action/count milestones. It is still not same-world parity: initial positions differ, the Unity witness did not capture a matching seed, complete consumed input masks or phase, and the formal playback report says `nativeParityClaim:false`. Collision, later projectile lifetime, draw pixels and other skills remain unverified. Q07/R17/R18 and the master goal remain open.
