六张合计：RGBA32 13.313 MiB；ASTC 4×4 3.337 MiB，减少 74.94%；ASTC 6×6 1.488 MiB，减少 88.82%。6×6 比 4×4 再少 55.39%。这是实际生成 ASTC 文件的纹理块数据，包含边缘补块，不是仅按 bpp 估算。每个 .astc 额外有 16 字节文件头；六文件含头合计分别为 3,498,720 / 1,560,832 字节。

原 PNG 六文件合计仅 334,246 字节；它们在磁盘上已经压缩，不能拿这个大小当纹理展开占用。ASTC 的主要价值是以压缩块形式供 GPU 采样。当前正式加载链未接入这些 ASTC；本次没有减少正式运行中的任何分配，也没有测量手机实际内存。

画质观察是本次静态样本的结论，不是人工美术验收或所有资源的统一通行标准：

- 角色像素细节优先考虑 4×4。6×6 在鸣人面部、裤装明暗和佐助衣服/腰带边缘出现更明显的颜色混合；4×4 更接近原图，但仍有局部色差。只统计原图可见像素的 RGB PSNR，鸣人为 34.43 / 23.84 dB，佐助为 38.13 / 27.00 dB（4×4 / 6×6，越高越接近）。
- 细线技能优先考虑 4×4。千鸟的细蓝线及高亮区域在 6×6 中出现更多色阶合并；螺旋丸的差异较小，但 6×6 也有颜色变化。千鸟整张可见像素 PSNR 为 37.20 / 25.19 dB，螺旋丸为 40.39 / 29.22 dB。压缩的始终是整张技能图，局部帧只是查看窗口。
- 火焰不能按“半透明特效都用 6×6”处理。放大后 6×6 明显合并红黄细碎纹理，4×4 也有损失。对原图的 4,861 个有效半透明像素，alpha 平均绝对误差为 10.69 / 29.64，数值范围 0–255；6×6 的透明边缘变化更大。
- 柔和烟雾可将 6×6 作为后续候选。其 61,687 个有效半透明像素的 alpha 平均绝对误差为 1.50 / 2.95；白底合成 RGB 平均绝对误差为 0.79 / 1.55。原尺寸较接近，放大和黑底下仍能看到渐变/局部色阶差异，不能称无损。

推荐只采用分类候选结论：角色与细线技能先看 4×4；柔和烟雾可评估 6×6；火焰和尖锐半透明边缘逐项保留质量判断。本轮没有更改 importer、原资源或默认格式。最终格式仍需要目标显示尺度/动画和支持 ASTC 的 GPU 路径验证。

本方案若后续正式接入，能控制的是这些纹理的 GPU 压缩块数据；CPU 解码像素、仍保留的 Color32[]、图集页缓冲、旧新资源同时驻留、上传暂存、驱动对齐、其他图集和渲染目标均不由这次采样证明受控。也不能将本表直接认作整批加载峰值或手机总进程上限。
