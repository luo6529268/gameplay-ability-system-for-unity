# Q07/F02 formal direct-spawn candidate catalog

Scope: a read-only screen of the current 336B44 playable object catalog. This closes only the question of whether a parsed OPoint directly creates a type-4/6 child in state 1000 with enough initial horizontal speed to meet F02's strict post-friction `|Vx| > 9` gate. It does not close F02, Q07, or the battle-alignment goal.

Authority: formal root `NTSD2.8-Logan.exe` SHA-256 `336B44E58BEA637246B65204AFC50FD8734C9AA38969B82836FA685497EB7BD3`; corresponding playable `source/ntsd28_core/src/simulation/object_spawning.cpp` (`ObjectSpawnPlanner28::plan_frame`), `physics_integrator.cpp` (`PhysicsIntegrator28::step`), and `resources/runtime` object catalog. Method: extended `Tools/NTSD28Q07Diagnostics/fast_weapon_natural_reachability_probe.cpp` with an isolated `discover-fast` mode. It enumerates every parsed parent OPoint whose positive child OID is type 4/6 and whose initial child action has state 1000. It records parent frame/state, immediate predecessor count, child, declared OPoint velocity, encoded facing/spawn count, and a conservative initial absolute X-speed bound `abs(dvx) + 5` for multi-spawn or `abs(dvx)` for a single spawn. In the playable planner, multi-spawn spread is within [-5,+5]; the bound holds regardless of facing/sign branch. This is an initial spawn-intent bound, not a measured post-friction velocity.

Twelve are OID 230 (`c/kan/a/kar.dat`) frames 135–140, 345–347, and 338–340, with declared `dvx=0` and 3–7 spawned children; their conservative initial `|Vx|` bound is 5. One is OID 22 (`c/shik/shik.dat`) frame 128, with declared `dvx=5`, single spawn, and bound 5. Thus **0/13 direct spawn intents have initial `|Vx| > 9`**. Each row has one immediate `next` predecessor in the parsed frame table; that count alone does not establish natural reachability.

Interpretation: direct OPoint birth is not a promising high-speed F02 natural witness under the current catalog. Neither formal root LFR nor original Unity Battle Scene was run for these catalog rows, because no qualifying direct-birth positive was found. The next bounded search should follow actual type-4/6 post-birth state transitions and velocity writes, then take a naturally reached strict `|Vx| > 9` case to formal-root and Unity Scene comparison.
