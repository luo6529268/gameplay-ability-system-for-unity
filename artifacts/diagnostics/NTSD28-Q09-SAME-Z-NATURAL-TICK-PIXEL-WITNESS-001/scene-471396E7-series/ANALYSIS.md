The stable underlay is not a reason to cherry-pick pixels. For **every** pixel where both single-weapon captures differ from baseline and from each other (82 pixels), the analysis tested both order models. With RGB vectors `U=baseline`, `A=a`, `B=b`, and `C=both`, the OID120-later model is `C = A + t(B-U)` for some `t` in [0,1]; the opposite is `C = B + u(A-U)`. For each model, least-squares `t`/`u` was clamped to [0,1], then the maximum per-channel residual was measured. All 82 pixels fit OID120-later with residual at most 0.27 of one 8-bit level. Only 38 fit the opposite within one level; **44 uniquely support OID120-later, zero uniquely support OID121-later, and none fail both models**. Seventy-seven composites exactly equal the `a` pixel; five are blended edge pixels, all fitting the OID120-later model. Example PNG pixel (1035,502): U=(130,130,130), A=(66,66,66), B=(102,102,93), C=(52,52,47), consistent with `t≈0.506`. The old exact-color-only `discriminatingOverlapPixels=0` report field is a probe-oracle limitation, not this independent four-image result.

These measurements establish that, for the actual tick-6 CentralOnly body overlap in this original Scene and the selected formal sprites, the GPU result is consistent with the formal descending-physical-slot painter order and has no opposite-order candidate.
